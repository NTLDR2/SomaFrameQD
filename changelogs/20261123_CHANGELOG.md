### 2. Breaking Changes (API, ABI, Packaging & Target Framework)

1. **Exclusive `.NET Framework 4.8` (`net48`) Single-Targeting:**
   * Dropped `net10.0-windows` multi-targeting across all 10 projects in [`src/SomaFrameQD.sln`](../src/SomaFrameQD.sln) and [`Caliburn5PackageHost.csproj`](../eng/compatibility/Caliburn5PackageHost/Caliburn5PackageHost.csproj).
   * Deleted the `.NET 10`-only project `eng/compatibility/MahApps.Net10DragHost/` (`MahApps.Net10DragHost.csproj`, `Program.cs`, `README.md`), removed `HelixToolkit.Core.Wpf` (`2.10.0`) from `SomaFrameQD.Demo.csproj`, and deleted `FolderProfileNet5.pubxml` (`net5.0-windows`) and `FolderProfileNetCore31.pubxml` (`netcoreapp3.1`).
2. **`Gemini` → `SomaFrameQD` Namespace, Assembly & NuGet Package Re-Identity:**
   * Renamed all core, module, demo, and test assemblies, root CLR namespaces, resource tables, and WPF pack URIs (`pack://application:,,,/SomaFrameQD;component/...`) from `Gemini*` to `SomaFrameQD*`.
   * Core library NuGet Package ID is **`SomaFrameQDWpf`** (assembly/namespace: **`SomaFrameQD`**); module NuGet Package IDs are `SomaFrameQD.Modules.{CodeCompiler,CodeEditor,ErrorList,GraphEditor,Inspector,Output,PropertyGrid}`.
   * XAML `[XmlnsDefinition]` URI in [`src/SomaFrameQD/Properties/AssemblyInfo.cs`](../src/SomaFrameQD/Properties/AssemblyInfo.cs) is `http://schemas.timjones.io/SomaFrameQD`.
3. **Split `Nerdbank.GitVersioning` Package-Line Reset (`1.1-beta` → `0.9.0` + `0.1.0` Demo):**
   * Reset root [`version.json`](../version.json) from `"1.1-beta"` to `"0.9.0"` (strict JSON without `//` comments) with `"pathFilters": [".", ":^src/SomaFrameQD.Demo"]`, and created [`src/SomaFrameQD.Demo/version.json`](../src/SomaFrameQD.Demo/version.json) (`"version": "0.1.0"`, `"pathFilters": ["."]`) so `SomaFrameQD.Demo` versions independently at `0.1.0` alpha.
4. **64-Bit (`x64` `PE32+`) Executable Host Architecture (`Q1 = 1A`):**
   * All executable projects (`OutputType` == `Exe` or `WinExe`: `SomaFrameQD.Demo`, `SomaFrameQD.Tests`, `Caliburn5PackageHost`) compile strictly with `<PlatformTarget>x64</PlatformTarget>` and `<Prefer32Bit>false</Prefer32Bit>` (`IMAGE_FILE_MACHINE_AMD64` = `0x8664`, `PE32+` magic = `0x020B`). 32-bit (`x86` / `WOW64`) host execution is unsupported.
   * All 8 packable library `.dll`s remain `AnyCPU` (`IMAGE_FILE_MACHINE_I386` = `0x014C` IL-only) so downstream `.NET Framework 4.8` `x64` or `AnyCPU` (`Prefer32Bit=false`) hosts consume standard NuGet `lib/net48/*.dll` assets cleanly.
5. **Replacement of Out-of-Band NuGet Shims with Native `.NET Framework 4.8` GAC References:**
   * Removed `System.ComponentModel.Composition` (`6.0.0`) from `SomaFrameQDWpf`'s NuGet dependencies and `System.Drawing.Common` (`6.0.0`) from `SomaFrameQD.Modules.Inspector`'s NuGet dependencies in [`eng/package-contract.json`](../eng/package-contract.json).
   * Both contracts now bind directly to `.NET Framework 4.8`'s built-in, pre-NGen'd `v4.0.0.0` GAC assemblies (`<frameworkAssembly assemblyName="System.ComponentModel.Composition" targetFramework=".NETFramework4.8" />` and `<frameworkAssembly assemblyName="System.Drawing" targetFramework=".NETFramework4.8" />`).
6. **Removal of `.NET 5+` Single-File Bootstrapper APIs (`Q3 = 3B`):**
   * Removed `protected virtual bool IsPublishSingleFileHandled`, `protected virtual IEnumerable<Assembly> PublishSingleFileBypassAssemblies`, and `CheckIfSomaFrameQDAppearsPublishedToSingleFile()` from [`src/SomaFrameQD/AppBootstrapper.cs`](../src/SomaFrameQD/AppBootstrapper.cs).
   * Replaced the commented-out single-file `DemoAppBootstrapper` stub with an active `.NET 4.8` [`DemoAppBootstrapper`](../src/SomaFrameQD.Demo/DemoAppBootstrapper.cs) wired in [`src/SomaFrameQD.Demo/App.xaml`](../src/SomaFrameQD.Demo/App.xaml).
7. **64-Bit Win32 `NativeMethods` Signature Changes:**
   * [`src/SomaFrameQD/Framework/Win32/NativeMethods.cs`](../src/SomaFrameQD/Framework/Win32/NativeMethods.cs): Changed `SetFocus(IntPtr hWnd)` return type from `int` to `IntPtr`; added `GetWindowLongPtr(IntPtr, int)` / `SetWindowLongPtr(IntPtr, int, IntPtr)` returning `IntPtr` in place of 32-bit `GetWindowLong`/`SetWindowLong` callers; switched `WNDCLASSEX`, `RegisterClassEx`, `CreateWindowEx`, `DefWindowProc`, `SendMessage`, `GetModuleHandle`, and `LoadCursor` to explicit `CharSet.Unicode` (`*W` entry points).

### 4. Catalog of Individual Bug & Defect Fixes (`0.9.0` / `0.1.0` Alpha)

1. **`x64` `WM_MOUSEWHEEL` Downward Scroll Crash (`System.OverflowException`):** `HwndWrapper.WndProc` previously called `wParam.ToInt32()`, which threw `OverflowException` on `x64` whenever scrolling down (`-120` = `0xFF88` in `HIWORD` → `0x00000000FF880000` > `int.MaxValue`). Fixed via `NativeMethods.GetWheelDeltaWParam(IntPtr)` (`UncheckedInt32`).
2. **`x64` Negative Multi-Monitor `WM_MOUSEMOVE` Crash (`System.OverflowException`):** Moving the cursor across a monitor positioned left of or above the primary display produced negative signed 16-bit `LPARAM` coordinates with bit 31 set (`0x00000000FFF6FFE7`), crashing `lParam.ToInt32()`. Fixed via `NativeMethods.GetXLParam` / `GetYLParam`.
3. **`x64` `WM_XBUTTONUP` Missed Button Release & High-Bit Overflow:** `HwndWrapper` previously checked `MK_XBUTTON1`/`MK_XBUTTON2` low-word state masks on `WM_XBUTTONUP` (already cleared on button release by Win32) and used `wParam.ToInt32()`. Fixed to inspect `HIWORD(wParam)` (`XBUTTON1` / `XBUTTON2`) via `NativeMethods.HighWord`.
4. **`NaN` Child `HWND` Creation Failure in `HwndWrapper` & `ClippingHwndHost`:** Casting default WPF `Width`/`Height` (`double.NaN`) to `(int)` yielded `unchecked((int)0x80000000)` (`int.MinValue`) in `CreateWindowEx` / `HwndSourceParameters`. Clamped fallback child dimensions to `>= 0` pixels via `GetSafeChildDimension`.
5. **32-Bit `GetWindowLong`/`SetWindowLong` & Premature `IntPtr.Zero` Calls in `WindowOptionsBehavior`:** Replaced 32-bit calls with 64-bit `GetWindowLongPtr`/`SetWindowLongPtr` and deferred style updates until `Window.SourceInitialized` when attached prior to `HWND` allocation.
6. **ANSI Win32 Class Registration & Truncated `SetFocus` Return Value:** Migrated `RegisterClassEx`, `CreateWindowEx`, `DefWindowProc`, `SendMessage`, `GetModuleHandle`, and `LoadCursor` to explicit Unicode (`*W`) P/Invokes and widened `SetFocus` return type from `int` to `IntPtr`.
7. **Continuous 60Hz VSync CPU Drain on Hidden/Inactive `HwndWrapper` Controls:** `HwndWrapper` previously kept `CompositionTarget.Rendering` attached for its entire lifetime even when collapsed or on an inactive AvalonDock tab. Gated subscription on `IsLoaded && IsVisible && _hWnd != IntPtr.Zero`.
8. **562 Unfrozen VS2013 `SolidColorBrush` Allocations & Unfrozen `PixelShader`s:** Added `po:Freeze="True"` across all 562 VS2013 theme brushes, froze AvalonDock 5 generated `Freezable`s, and cached frozen `PixelShader` instances with `ShaderRenderMode.Auto`.
9. **Invisible Borderless Main Window Frame on Windows 7 Classic / Aero Basic / Non-DWM RDP:** Added explicit `1px` `MainWindowActiveBorder`/`MainWindowInactiveBorder` fallback border to `MainWindowStyle` when DWM `GlowBrush` composition is unavailable.
10. **Windows 7 TLS 1.0 Handshake Failures vs. Windows 11 Blocked TLS 1.3:** Added OS-adaptive `ResolveCrossOsSecurityProtocol` upgrading `SystemDefault` (`0`) to `Tls12` on `NT 6.1` while keeping `SystemDefault` on Win8.1/Win10/Win11 so TLS 1.2 + TLS 1.3 negotiate natively.
11. **Oversized Default Main Window (`1000×800`) Clipping on `1024×768` / `1366×768` Displays & Sub-Pixel Blur:** Clamped `MainWindowViewModel` / `MainWindowView` startup dimensions to `SystemParameters.WorkArea`, enabled `SnapsToDevicePixels="True"` and `UseLayoutRounding="True"` on `MainWindowView`, and tuned ClearType `TextFormattingMode` (`Display` at `96 DPI`, `Ideal` at High-DPI).
12. **CLR `.NET 4.6.1` Quirk Mode in `app.config`:** Updated `sku=".NETFramework,Version=v4.6.1"` to `sku=".NETFramework,Version=v4.8"` in both `SomaFrameQD` and `SomaFrameQD.Demo`.
13. **CWD-Fragile MEF Startup Probing, Native-DLL Crash Risk & Excess BCL/Vendor Reflection:** Switched MEF probing from `".\\"` to `AppDomain.CurrentDomain.BaseDirectory`, added `ShouldInspectAssemblyFile` vendor/BCL skip-filter, caught `BadImageFormatException`, and `using`-disposed `AssemblyCatalog` probes.
